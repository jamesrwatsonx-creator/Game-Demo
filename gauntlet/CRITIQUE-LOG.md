## Critique effectiveness note

CQ-01 through CQ-04 were all decision-changing and all surfaced *during construction*, not
during a separate post-hoc review pass — consistent with this build's broader finding
(`gauntlet/TIMELINE.md` "Timing findings") that a fast, headless, automated evaluation
harness run continuously during construction functioned as the most effective critic in this
session, cheaper and faster than a dedicated critique phase would have been. CQ-05/CQ-06 are
the two findings that came from a deliberate, separate close-reading pass at the end of the
rendering phase — both real, neither as high-leverage as the harness-driven findings. This is
itself evidence for `gauntlet/META-LEARNING.md`'s eventual research-sequencing conclusions.

## Critique quality checks

For material critiques, ask:
- Did it challenge an upstream assumption or only polish implementation?
- Did it overfit the benchmark?
- Did it confuse preference with evidence?
- Did acting on it measurably improve the game?
- Would this critic have been more valuable earlier or later?
