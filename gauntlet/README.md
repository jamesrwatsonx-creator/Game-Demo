# Gauntlet Experiment Artifacts

This directory is the lightweight flight recorder for Game Build Experiment #1.

- `EXPERIMENT.md` — immutable baseline and experimental questions.
- `EPISTEMIC-STATE.md` — invariants, priors, hypotheses, observations, contradictions, revisions.
- `CONSTRAINT-LEDGER.md` — dependency-aware current constraint state.
- `TIMELINE.md` — material event order and timing-of-intelligence evidence.
- `DECISIONS.md` — consequential decision provenance.
- `INTERACTIONS.md` — conditional outcomes, confounders, and surrounding state.
- `CRITIQUE-LOG.md` — independent critique and observed consequence.
- `GAPS.md` — missing intelligence/capabilities and when they would have helped.
- `HUMAN-INTERVENTIONS.md` — automatically captured material creator interventions.
- `EFFICIENCY.md` — useful, confidence-changing, premature, and wasted work plus observable telemetry.
- `WORK-LOG.md` — major prototypes, pivots, dead ends, and rebuilds.
- `META-LEARNING.md` — end-of-run extraction for the future Game Gauntlet.
