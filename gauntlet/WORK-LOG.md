## Timing note

All five entries above (WL-01 through WL-05) occurred within a single tight build-test-fix loop before any rendering code existed — i.e., before the "first playable" milestone, using only headless Vitest. This is the clearest evidence in this run for section 36 ("build/test instead of reason"): each of these four issues (two implementation bugs, one test-harness bug, one real design-tension finding) would have been far more expensive to find visually in a 3D prototype than they were to find here, where the sim is decoupled from rendering and runs thousands of matches per second headlessly. See gauntlet/META-LEARNING.md for the generalized lesson.
